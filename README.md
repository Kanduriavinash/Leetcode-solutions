# 🧩 LeetCode Solutions

A personal collection of solutions to coding challenges, maintained while practising **data structures, algorithms, and problem-solving**.

The goal is to build a consistent problem-solving habit, understand multiple approaches, and improve the ability to reason about correctness and efficiency.

## 🎯 What this repository is for

- Practising common data structures and algorithms
- Translating problem statements into clear solutions
- Comparing approaches and reasoning about trade-offs
- Keeping a record of problems solved over time

## 📝 A useful way to review a solution

When working through a problem, consider recording:

1. **Problem** — link to the original challenge
2. **Approach** — the key idea behind the solution
3. **Complexity** — time and auxiliary-space complexity
4. **Edge cases** — important boundary conditions

Solution languages and file organization are determined by the source files in the repository.

## 🚀 Getting started

Clone the repository:

```bash
git clone https://github.com/Kanduriavinash/Leetcode-solutions.git
cd Leetcode-solutions
```

Open a solution file in the editor appropriate for its language and run it using that language's standard toolchain.
